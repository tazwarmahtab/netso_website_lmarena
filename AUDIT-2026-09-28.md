## 1. 🔴 Content leak — internal note in production `about` page

**Evidence:** `about/index.html` (built) line ~248 contains, verbatim:

```html
<!-- ============================== ORIGIN ================================
     Factual scaffold. The founder's name, role, chronology and any personal
     background must be supplied by the company before launch — see README
     ("Founder story"). Nothing specific is invented here.
     ==================================================================== -->
```

Two problems:
1. **It's an internal instruction visible in production page source** — anyone who "view-source"s the About page reads Netso's internal editorial process.
2. **It's stale.** The founder section immediately below it now *does* name the founder ("Tazwar Mahtab, Founder & CEO"), so the note contradicts the finished content.

**Root cause (finding #14):** `tools/build.py`'s `INTERNAL_COMMENT` regex is `<!--\s*(?:INTERNAL|TO BE SUPPLIED)…-->` — it only strips a comment when `INTERNAL`/`TO BE SUPPLIED` is the **first token**. This comment opens with an `===== ORIGIN =====` divider, so it slipped through. The same-file terms/privacy counsel notes *were* stripped because they start with `INTERNAL —`.

**Fix:** either (a) delete the note from `src/pages/about.html`, or (b) strengthen the stripper to remove *all* HTML comments from production output (see #20), which also fixes the 37 leftover comments in one move.

## 6. 🟠 Colour-contrast failures (WCAG AA, computed)

Measured against the actual tokens. AA needs **4.5:1** for normal text, **3:1** for large/bold ≥24 px.

| Token / usage | Ratio | Verdict |
|---|---|---|
| `--muted-2` `#8E9297` on paper — `.sec-head__idx`, `.statcard__idx`, `.phase__idx`, `.field__opt` "(if known)", `.field__hint`, many mono labels | **2.82** | ❌ fails badly |
| `--muted` `#6E7276` on paper — `.small`, `.text-muted` | **4.37** | ❌ just under 4.5 |
| `rgba(255,255,255,0.4)` on `#101215` — `.cta__meta`, footer meta | **3.84** | ❌ fails |
| `--solar` `#E3841B` as text on paper | 2.50 | ⚠️ only used on hover/borders, not body text — OK today |
| `rgba(255,255,255,0.45)` vision labels on `--void` | ~4.3 | ⚠️ borderline |

The `--muted-2` failures matter most because `.field__opt` ("(if known)") and `.field__hint` are **instructional form text**, not decoration. **Fix:** darken `--muted-2` to ≈`#6E7276` and `--muted` to ≈`#5E6266`; raise the dark-section label alpha from 0.4→0.55.

## 7. 🟠 Form errors aren't announced to assistive tech

`DL.initForm` toggles a `.is-invalid` class (revealing a `.field__error` span via CSS) and moves focus to the first bad field. But it never sets **`aria-invalid`** on the input, and the error text isn't linked via **`aria-describedby`**. A screen-reader user lands on the field with no announcement of *what* is wrong. **Fix:** on failure set `aria-invalid="true"` and wire each input to its `.field__error` id with `aria-describedby`; clear on correction.

## 8. 🟠 Non-sequential heading levels

Verified across all pages:
- **Every page:** footer column titles are `<h4>` following a section `<h2>` → skips h3.
- **`/start-a-project`:** `<h1>` → `<h3>` (form/aside headings skip h2).
- **`/404`:** `<h1>` → `<h4>` (footer).

Not catastrophic, but it breaks the document outline for screen-reader navigation. **Fix:** make footer titles `<h2>` (or style h2s down), and lift the start-page section headings to `<h2>`.

---

## 9. 🟠 `prefers-reduced-motion` partially ignored on the hero

`home.js` builds the hero copy timeline (`gsap.timeline()` → `y` translate on title/sub/model/top/cta/steps/proof) **unconditionally**, *before* the `if (DL.reduceMotion)` branch. That branch only governs the rooftop→solar **stage sequence**. So a visitor who set "reduce motion" still gets the slide-up reveal on the hero copy. (CSS `!important` forces the opacity visible, so it's transform-only motion, but it is motion.) **Fix:** skip/curtail the copy timeline when `DL.reduceMotion` is true.

---

## 10. 🟠 GSAP suite loads on pages that don't need it

`build.py` injects all four vendor libs — `gsap` (72 KB) + `ScrollTrigger` (44 KB) + `SplitText` (7 KB) + `lenis` (16 KB), ≈**50 KB gzipped** — on **every** route, including `/legal/*` and `/404`, which use almost none of it. **Fix:** gate vendor injection per page (legal/404 need at most Lenis, arguably nothing). *Licensing note:* GSAP is 3.13.0, which is free under GreenSock's standard license as of 2025 — no licensing blocker.

## 11–12. 🟠 Dead / misleading code

- **#11 `DL.parallax`** — defined in `core.js`, **zero call sites** (confirmed by grep). This was flagged in the earlier `ANIMATION-AUDIT.md` and is still unresolved. Wire it or delete it.
- **#12 `canvas[data-logo-intro]`** — `core.js` `header()` gates the header reveal on a `<canvas data-logo-intro>` that **does not exist** anywhere (leftover from the Daylight Rive intro). So the header always falls through to the `setTimeout(onReady, 260)` path, and the `dl:introPlayed` event that `home.js`/page scripts dispatch is **never consumed**. Harmless but misleading — remove the canvas branch or wire the event properly.

## 15–20. 🟡 Lower-severity / polish

- **#15 Locale mismatch:** `<html lang="en">` but `og:locale="en_GB"`. Pick one (copy uses a mix, e.g. "metre" vs "-ize"); align to `en_GB` or `en_US` consistently.
- **#16 SEO extras:** single static `theme-color:#F5F3EF` shows light browser chrome even on the dark hero/CTA pages; and there's **no JSON-LD** (`Organization`/`LocalBusiness`) — a cheap win for brand rich-results.
- **#17 Focus indicator on inputs:** `.field input:focus { outline:none; border-color:var(--ink) }` replaces the global 2 px focus ring with a subtle border change — weaker for keyboard users. Keep a visible ring.
- **#18 Image format:** content JPGs (`facility-textile` 200 KB, `pipeline-industrial` 250 KB, `how-*` ~200–240 KB, `grid-infrastructure` 233 KB) are JPEG; the hero already uses WebP. Converting saves ~30% each. All are lazy-loaded, so impact is modest.
- **#19 JS-fail resilience:** the inline `<head>` script adds `html.anim` (hiding hero CTA/top/proof/steps + translating the header off-screen) with a **4.5 s** failsafe removal. If JS is *enabled but the main bundle fails to load*, those elements stay hidden for up to 4.5 s. (With JS fully disabled the inline script never runs, so content shows immediately — fine.) Consider shortening the failsafe to ~2 s.
- **#20 Comments in output:** 37 structural HTML comments ship to production (minor bytes + exposes section structure). Strip in the production build.
